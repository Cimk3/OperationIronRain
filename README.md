# 代号：铁雨（Operation // Iron Rain）

基于 **TypeScript + Vite + Three.js + WebGL 2.0 + Web Audio API / AudioWorklet + Web Worker** 构建的**100% 零外部美术/音频资源纯代码程序化写实军事战术 PVE FPS Demo**。  
所有三维模型、PBR 法线/粗糙度/金属度/AO 贴图、地形与植被、骨骼蒙皮动画、体积雾/水坑反射后处理以及枪械与环境音效均由程序实时算法合成生成。
在线游玩：https://cimk3.github.io/OperationIronRain/
---

## 核心特性

### 1. 纯程序化高画质渲染管线（默认 100% 原生分辨率）
- **Half-Float HDR + ACES Filmic 色调映射 + FXAA 抗锯齿 + 自适应 Bloom 辉光**
- **屏幕空间环境光遮蔽（GTAO）与水洼屏幕空间实时反射（SSR）**，带雨滴同心涟漪扰动
- **级联阴影贴图（CSM，高画质 3×2048 PCFSoftShadowMap）** + 体积阳光散射（God Rays）
- **世界空间 Triplanar 地形混合着色**与 1024×1024 / 2048×2048 程序化 PBR 纹理库（金属拉丝、边缘露白磨损、模具接缝混凝土与渗水干湿对比）

### 2. 双战役关卡
- **第一关：《雨夜林地哨站》**
  - 250m × 250m 水力侵蚀山谷（Web Worker 异步生成），L-System 分叉乔木、15,000+ GPU 实例化草丛/蕨类、实心沙袋掩体、木围栏前哨与暴雨雷声天气系统
  - 三阶段突围：突破外围巡逻哨 → 夺取前哨通讯终端 → 抵达西北山脊撤离点（LZ）
- **第二关：《深夜渗透 · 地下导弹发射井》**
  - 全长 180m 紧凑封闭式地下设施：暴雨地面入口与防爆门 → 带防滑纹倾斜坡道 → “主宽通道 + 侧翼电缆暗道 + 发电机房”平行管廊 → 三层垂直导弹发射井大厅与二层环形金属栈道
  - **高信息密度工业建模 & 性能优化**：按区域材质合批（`mergeGeometries`）大幅压低 Draw Call，全关仅保留 ≤ 2 盏实时阴影光源，动态筛选距离最近的 ≤ 6 盏无阴影点光源配合烘焙光晕与区域可见性剔除
  - **可破坏走廊照明 & 红色警报突围**：射击头顶荧光灯管熄灭照明以缩减敌兵索敌视野；黑入主控终端 `[E]` 触发全区红色旋转警报与增援追击，沿东侧逃生斜坡冲出地面撤离

### 3. 五款高精度程序化武器与 3D 实时改枪面板（Gunsmith）
- **M4A1 SOPMOD**（5.56mm 全自动卡宾）
- **AR-15 MATCH DMR**（18 英寸刻槽不锈钢重管、M-LOK 护木、镂空枪托、20 发直插弹匣、半自动高精高伤）
- **SIG M7 (XM7)**（FDE 沙色与深灰金属双色调、一体式增高上导轨、侧折叠枪托、双侧拉机柄、6.8×51mm 全威力战斗步枪）
- **MP5SD TACTICAL**（9mm 整体消音冲锋枪，带“HK Slap”空仓拍击换弹与潜行低噪 14m 声学半径）
- **M1911 TACTICAL**（.45 ACP 备用手枪，空仓挂机与套筒复进机构）
- **3D 实时改枪工作台**：主菜单及简报页可随时进入，支持 360° 拖拽旋转、滚轮缩放、枪身 3D 槽位节点热插拔替换（瞄具 / 枪口 / 下挂 / 侧导轨手电 / 弹匣，含卡扣音效与 `localStorage` 自动保存），以及 5 项实时性能对比条
- **第一人称双臂动态 IK**：依据是否加装**垂直握把**或**直角握把**实时切换左手 Two-Bone IK 与五指握持姿态，右键 ADS 自动对齐机瞄 / 红点 / 全息光学中心

### 4. 自定义片元着色器粒子、AI 碰撞与程序化音频
- **材质感知命中特效**：混凝土柔和烟尘团 + 深色不规则碎石屑 + 弹孔贴花；金属高速拉伸橙黄 HDR 火花（带弹性反弹）+ 焦黑刮痕；水洼溅射与扩张涟漪；敌兵暗红血雾
- **AI 实体碰撞与防穿墙校验**：士兵移动执行双遍胶囊体滑移碰撞、出生点/路径点安全边距清洗与枪口视线防穿墙校验
- **Web Audio API / AudioWorklet**：实时粉噪暴雨声、随距离延迟雷声、消音/制退器/重型步枪分层枪声合成、弹壳落地金属声以及室外/地下混凝土混响无缝切换

## 操作按键说明

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | `W A S D` / `Shift` |
| 跳跃 / 蹲伏 | `Space` / `C` 或 `Ctrl` |
| 射击 / 机械·光学瞄准 (ADS) | `鼠标左键` / `鼠标右键` |
| 战术换弹 | `R` |
| 切换主副武器 / 快速测试枪械 | `1`（主武器）/ `2`（M1911）/ `3` MP5SD / `4` AR-15 / `5` M7 / `Q` 或滚轮 |
| 战术手电筒（需侧导轨已挂载） | `F` |
| 交互 / 黑入发射井终端 | `E` |
| 暂停 / 释放鼠标指针 | `P` 或 `ESC` |

## 本地运行与构建

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# TypeScript 类型检查 + 生产构建 (dist/ 未压缩总体积 < 1 MB，远低于 30MB 红线)
npm run build

# 启动生产预览服务
npm run preview
```

## 项目结构

```text
src/
├── audio/ProceduralAudio.ts    # Web Audio + AudioWorklet 枪声/暴雨/雷鸣/混响合成引擎
├── engine/
│   ├── atmosphere.ts           # 天空盒、暴雨粒子、闪电与环境 IBL
│   └── postprocess.ts          # Half-Float HDR + GTAO + SSR + Volumetric Sun Shafts + Bloom + ACES + FXAA
├── gameplay/
│   ├── combat.ts               # 射线弹道、软烟尘/拉伸金属火花/涟漪/程序化弹孔贴花
│   ├── enemies.ts              # 敌方人形骨架、2-Bone IK、AI 状态机与防穿墙碰撞体系
│   ├── loadouts.ts             # 枪械数值、配件属性计算与 localStorage 存档
│   ├── player.ts               # 第一人称胶囊体移动、坡道贴合与低血量恢复
│   └── viewmodel.ts            # 双阶弹簧阻尼视模动画、ADS 对齐、换弹与握把动态 IK
├── proc/
│   ├── arms.ts                 # 第一人称双臂蒙皮网格与 5 指握姿（护木/垂直握把/直角握把/手枪）
│   ├── attachments.ts          # 通用瞄具/消音/制退器/握把/手电/弹匣槽位构建与挂载系统
│   ├── modeling.ts             # 倒角箱体、车削 Lathe、样条扫掠与皮卡汀尼导轨几何生成器
│   ├── noise.ts                # Simplex/FBM/Worley 算法
│   ├── textures.ts             # 1024/2048 PBR 程序化贴图合成库
│   └── weapons.ts              # M4A1、AR-15、SIG M7、MP5SD、M1911 高面数武器建模
├── ui/gunsmith.ts              # 3D 实时改枪工作台、3D 节点投影交互与性能面板
├── workers/terrain.worker.ts   # Web Worker 250m 水力侵蚀地形与散射生成
└── world/
    ├── outpost.ts              # 第一关哨站掩体、沙袋与检查点
    ├── silo.ts                 # 第二关 180m 地下发射井（合批优化、可碎灯管、全封闭碰撞与警报）
    ├── terrain.ts              # Triplanar 地形着色器
    └── vegetation.ts           # L-System 树木与 GPU 实例化植被
```
